# 그림 파일 넣는 곳

이 폴더에 아래 이름으로 PNG 파일을 넣으면 게임에서 자동으로 사용됩니다.
없는 파일은 기본 이모지 그림으로 표시됩니다.

| 파일 이름 | 심볼 |
|---|---|
| wild.png | WILD (용) |
| lion.png | 사자상 (최고 배당) |
| butterfly.png | 나비 |
| toad.png | 두꺼비 |
| koi.png | 잉어 |
| bonsai.png | 분재 |
| a.png, k.png, q.png, j.png, 9.png | 글자 심볼 |
| bonus.png | 보너스 (프리 스핀 스캐터) |
| coin.png | 코인 (홀드 앤 스핀) |
| background.png | 전체 배경 (선택) |

권장: 정사각형, 투명 배경 PNG, 256×256 이상.
본인이 만들었거나 상업적 사용이 허용된 이미지만 사용하세요.
